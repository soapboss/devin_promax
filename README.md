# Davin Pro Max

在 Devin Local 中使用 Davin Pro Max 云端高级模型：授权码激活、兑换码充值、按量计费、自动更新。

## 下载与安装

1. 在右侧 **[Releases](../../releases/latest)** 下载最新的 `davin-pro-max-x.y.z.vsix`
2. 打开 Devin → 扩展 → 右上角 `…` → **从 VSIX 安装…**，选择下载的文件
3. 点击左侧活动栏的 **Davin Pro Max**，输入授权码激活

已安装的插件会在每次启动 Devin 时自动检查更新并提示，一键即可升级，无需手动下载。

## 1.2.6 更新

**修复：新电脑安装后要反复关闭 Devin 才显示自定义模型。**

- 根因：Devin 只在拉起 Devin Local 代理的那一刻读取一次设置，代理启动时若设置或本地网关未就绪就会一直“未认证”；而重连命令要等到 Devin 自己的网络/登录阶段才出现，旧版只重试 15 秒，常常不够，盲目重连还会打断握手。
- 插件现在最先启动本地网关并写入设置；再读取 Devin 自己的 ACP 日志，只统计设置与网关都生效之后的认证。代理第一次启动就用对了设置则**不重连**，确实没用上才重连，次数有上限，并说明原因（未登录、工作区未信任、网络无法访问 Devin 服务等）。
- 重载提示合并为一条并说明全部原因；面板显示“正在连接 / 已连接”。

**新增：禁止 Devin 客户端自动更新。**

- 设置项 `davinProMax.blockClientUpdates`（默认开启，面板「设置」页有开关）：写入 Devin 官方设置 `update.mode = "none"`（Windows 同时关闭后台更新），不修改程序文件。
- 需**完全退出 Devin 后重新打开**才对运行中的进程生效；面板读取 Devin 当次启动日志，确认“更新已禁用”才显示“已拦截”。Devin 在该设置变化时会自己弹出“需要重启”，已与补丁所需的重启合并为一次。
- 关闭开关或卸载插件时还原你原来的值；企业策略优先时只提示。已下载好的安装包、已在运行的后台安装程序无法由插件停止。**不更新会错过官方的安全与错误修复。**

完整说明见 [RELEASE_NOTES.md](RELEASE_NOTES.md)。安装包 `davin-pro-max-1.2.6.vsix` 的 SHA-256 见 [校验文件](davin-pro-max-1.2.6.vsix.sha256)。

### 使用条件与验证记录

- 请登录 Devin、激活插件、信任当前工作区并选择 Devin Local。首次安装只需**完全重启 Devin 一次**（关闭所有窗口，包括 Agents 窗口；Devin 弹出“需要重启”时点“重启”即可）。
- 自动化回归测试：**142 项通过**，类型检查通过。
- 真实客户端隔离模拟（全新配置，Next 3.11.1108 与稳定版 3.10.48 各启动两次）：网关 1 秒内就绪，代理约 9 秒后拉起并认证，插件约 10 秒确认连接，重连 0 次。原生 CLI 的冷/热缓存与“网关晚启动”实验均已通过，测试不发送聊天。
- 稳定版所在机器以管理员身份运行，Devin 本就因此关闭更新，所以稳定版上无法单独证明是插件设置在起作用；设置生效已在 Next 版上由 `disabled by user preference` 确认。
- macOS/Linux 仅有路径、设置文件与状态逻辑的自动化测试，**未进行实机图形界面验收**。macOS 应用目录需允许 Devin 写入；未知构建或权限受限时不能保证自动修复。
