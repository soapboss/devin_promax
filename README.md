# Davin Pro Max

在 Devin Local 中使用 Davin Pro Max 云端高级模型：授权码激活、兑换码充值、按量计费、自动更新。

## 下载与安装

1. 在右侧 **[Releases](../../releases/latest)** 下载最新的 `davin-pro-max-x.y.z.vsix`
2. 打开 Devin → 扩展 → 右上角 `…` → **从 VSIX 安装…**，选择下载的文件
3. 点击左侧活动栏的 **Davin Pro Max**，输入授权码激活

已安装的插件会在每次启动 Devin 时自动检查更新并提示，无需手动下载。

请只从本页面 Releases 或插件内置更新获取安装包。
